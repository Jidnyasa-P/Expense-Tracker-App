# 📊 AI Expense Tracker & Data Insights

A professional, data-driven financial dashboard built as a proof-of-concept for modern FinTech applications. This project demonstrates full-stack development, data visualization, and AI integration.

## 🌟 Key Features
- **📊 Interactive Visualizations**: Dynamic charts showing spending trends and category distributions using Recharts.
- **🤖 AI Financial Analyst**: Integrated Gemini 2.0 Flash API to analyze spending patterns and provide personalized recommendations.
- **⚡ Synthetic Data Engine**: Instant generation of realistic financial records for demonstration and testing.
- **🎨 Modern FinTech UI**: Clean, professional interface built with Tailwind CSS and Framer Motion.
- **🧹 Data Science Lifecycle**: Demonstrates the full pipeline from raw transaction data to meaningful business insights.

## 🛠️ Tech Stack
- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS 4.0, Lucide Icons
- **Visualization**: Recharts
- **Backend**: Node.js (Express)
- **AI**: Google Gemini API (@google/genai)
- **Utilities**: date-fns, clsx, tailwind-merge

## 🚀 Getting Started
1. **Configure API Key**: Ensure your `GEMINI_API_KEY` is set in the Secrets panel.
2. **Generate Data**: Click the "Quick Demo Data" button to populate the dashboard.
3. **Analyze**: Click "Generate Insights" to see the AI analyze your spending behavior.

## 📈 Data Points Tracked
- Transaction Date & Type (Income/Expense)
- Expense Categories (Food, Bills, Transport, etc.)
- Descriptions & Transaction amounts
- Daily and Monthly Trends
